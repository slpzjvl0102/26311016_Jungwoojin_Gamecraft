# 아레나 서바이버 게임 기획서

- 목적: 기말 과제 게임 기획서
- 작성자: 정우진
- 개발 환경: Unity 6 / C#
- 플랫폼: PC (Windows)

## 1. 개요

- 장르: 2D 탑다운 액션게임
- 콘셉트: 작은 전투장에서 적의 공격을 피하고 모든 적을 처치하는 게임
- 플레이 인원: 1명
- 예상 플레이 시간: 1회 약 3~5분
- 핵심 재미: 적의 공격 타이밍을 보고 회피한 뒤 빈틈을 노리는 전투

## 2. 게임 진행

1. 시작 화면에서 게임을 시작합니다.
2. 플레이어는 전투장 중앙에서 등장합니다.
3. 각 Wave에 등장하는 적을 모두 처치하면 다음 Wave가 시작됩니다.
4. Wave 사이에는 5초의 준비 시간이 주어지며 체력을 1 회복합니다.
5. 마지막 Wave의 보스를 처치하면 승리합니다.
6. 체력이 0이 되면 패배하며, 결과 화면에서 다시 도전할 수 있습니다.

## 3. 조작

- W / A / S / D: 이동
- 마우스 이동: 바라보는 방향 지정
- 마우스 왼쪽 클릭: 해당 방향으로 근접 공격
- Space: 이동 방향으로 짧게 회피 (정지 상태에서는 바라보는 방향)
- Esc: 일시정지 / 재개

## 4. 전투 규칙

- 플레이어 체력은 5이며, 적에게 피격되면 1 감소합니다.
- 기본 공격은 전방의 짧은 범위에 피해 1을 줍니다.
- 공격 간격은 0.4초이며, 공격 범위 안의 적을 함께 타격합니다.
- 회피는 0.2초 동안 빠르게 이동하며, 해당 시간에는 피해를 받지 않습니다.
- 회피 재사용 대기시간은 1초입니다.
- 피격 후 0.7초 동안 무적 상태가 되어 연속 피해를 방지합니다.
- 적은 공격 전 색상 변화 또는 바닥 표시로 공격 방향을 알립니다.
- 수치는 초기 기준이며, 플레이 테스트 후 조정합니다.

## 5. 적 구성

### 추격병

- 체력: 2
- 행동: 플레이어에게 접근한 뒤 짧은 준비 동작 후 근접 공격
- 역할: 이동과 기본 공격을 익히게 하는 기본 적

### 돌진병

- 체력: 3
- 행동: 플레이어 방향을 조준하고 0.8초 후 직선으로 돌진
- 약점: 조준이 끝나면 방향을 바꾸지 않으며, 돌진 후 잠시 멈춤

### 보스: 아레나 가디언

- 체력: 15
- 행동: 직선 돌진과 주변 범위 공격을 번갈아 사용
- 약점: 공격 후 1초 동안 멈추며 반격 기회를 제공

## 6. 플레이 Stage

- Stage는 화면 안에 전체가 보이는 단일 전투장으로 구성합니다.
- 전투장 외곽은 벽으로 막혀 있으며, 낭떠러지와 장애물은 배치하지 않습니다.
- 적은 외곽의 고정 지점에서 1초간 등장 위치를 표시한 후 생성됩니다.
- 각 Wave의 적은 동시에 등장하며, 추가로 생성되지 않습니다.

### Wave 1

- 추격병 3마리
- 목표: 이동과 기본 공격 익히기

### Wave 2

- 추격병 3마리 + 돌진병 2마리
- 목표: 여러 적을 상대하며 회피 타이밍 익히기

### Wave 3

- 보스 1마리
- 목표: 공격 예고를 읽고 빈틈에 반격하기

## 7. 화면 구성

- 시작 화면: 게임 제목, 시작 버튼, 종료 버튼
- 게임 화면: 플레이어 체력, 현재 Wave, 남은 적 수, 회피 대기시간
- 일시정지 화면: 계속하기 버튼, 시작 화면으로 돌아가기 버튼
- 결과 화면: 승리 / 패배 표시, 플레이 시간, 다시하기 버튼

## 8. 개발 범위와 우선순위

1. 플레이어 이동, 방향 전환, 공격, 피격 구현
2. 추격병과 전투장 구현
3. 회피와 돌진병 구현
4. Wave 진행, 승리 / 패배, 재시작 구현
5. 보스와 UI 구현
6. 공격 효과음, 피격 연출, 난이도 조정

- 필수 범위: 캐릭터 1종, 일반 적 2종, 보스 1종, Stage 1개
- 제외 범위: 장비, 성장, 아이템, 저장, 멀티플레이
- 완료 기준: 시작부터 결과 화면까지 진행되고, 재시작 시 모든 상태가 초기화됩니다.
